· 오른손: 엄지(p)=6·5번줄 베이스, 검지(i)=3번줄, 중지(m)=2번줄, 약지(a)=1번줄.
· 각 마디 = 코드 2개(2박씩), 패턴: 베이스 → 3번줄 → 2번줄 → 1번줄 순의 8분음표 아르페지오.
· 못갖춘마디의 A–B–C#(3번줄 2프렛 → 2번줄 0 → 2번줄 2)은 피아노 오른손 픽업 라인을 딴 것 — 가볍게 밀고 들어가면 됨.
· 피아노 원본의 16분음표 잔가락은 기타 울림에 맞춰 8분음표로 단순화한 버전. 좀 더 화려하게 원하면 각 코드의 1번줄 음을 해머온/풀오프(예: 1번줄 2↔3)로 꾸며도 잘 어울림.
· 마지막 G에서 저음 G(6번줄 3프렛)+개방현을 울려두고 그대로 본 반주(스트럼/아르페지오) 시작.
