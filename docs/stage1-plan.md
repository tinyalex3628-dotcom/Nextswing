# 스윙 유형 테스트 — 1단계 기획 (축 설계 + 문항 + 채점 로직)

> 상태: **확정 (v1.1)** — 검토 의견 반영: Q7·Q12 교체, Q11 문구 조정, 측정 개념/표시명 분리

## 1. 축 4개

유형 코드 순서: **공략 → 접근 → 목적 → 멘탈** (예: `AFWI`)

내부 측정 정의(채점·검증용)와 결과 화면 표시명(마케팅용)을 분리한다.

| # | 축 | 코드 | 내부 측정 정의 | 결과 표시명 |
|---|----|------|----------------|-------------|
| 1 | 코스 공략 | **A / S** | 위험 감수형 / 위험 관리형 — 기회가 보이면 치는가, 다음 샷을 생각하는가 | 공격형 / 안전형 |
| 2 | 골프 접근 방식 | **F / T** | 감각 해결형 / 원인 분석형 — 골프 문제를 감으로 푸는가, 이유를 찾아 푸는가 | 감각형 / 분석형 |
| 3 | 라운드 성향 | **W / J** | 결과형 / 경험형 — 라운드에서 남는 게 스코어인가, 경험인가 | 승부형 / 힐링형 |
| 4 | 멘탈 | **I / G** | 리셋형 / 몰입형 — 실수를 바로 넘기는가, 오래 곱씹는가 | 강철멘탈 / 유리멘탈 |

설계 노트:
- "파워vs컨트롤"과 "공격vs안전"은 사실상 같은 성향이라 코스 공략 하나로 통합. 대신 한국 아마추어 문화 공감대가 큰 "승부vs힐링" 축 추가.
- 유리멘탈 축은 바이럴 핵심. 단, 결과 설명 문장은 "한 샷에 오래 몰입하는 편"처럼 존중하는 톤으로 쓰고, 유머는 카드 표시명에서만.
- 코드 8종(A/S/F/T/W/J/I/G) 중복 없음.

## 3. 채점표

- 선택지 하나당 해당 극에 **+2점**. 축당 3문항 → 축 총점 6점.
- 축별 점수 조합은 6:0 / 4:2 / 2:4 / 0:6 만 가능 → **동점(3:3) 구조적으로 불가능**.
- 유형 코드 = 각 축에서 점수가 높은 극의 알파벳 4개 (공략→접근→목적→멘탈 순).
- 결과 화면 퍼센트 = 축 점수 / 6 × 100 (표시값: 100% / 67% / 33% / 0%).

| 축 | 문항 | 극1 (+2) | 극2 (+2) |
|----|------|----------|----------|
| 공략 | Q2, Q5, Q10 | A(공격): Q2-A, Q5-A, Q10-B | S(안전): Q2-B, Q5-B, Q10-A |
| 접근 | Q3, Q7, Q11 | F(감각): Q3-A, Q7-B, Q11-A | T(분석): Q3-B, Q7-A, Q11-B |
| 목적 | Q4, Q8, Q12 | W(승부): Q4-B, Q8-A, Q12-A | J(힐링): Q4-A, Q8-B, Q12-B |
| 멘탈 | Q1, Q6, Q9 | I(강철): Q1-A, Q6-A, Q9-B | G(유리): Q1-B, Q6-B, Q9-A |

## 4. 자체 검증표

### 4-1. 축 내 일관성

| 축 | 공통 성향 | 3문항의 상황 분산 |
|----|-----------|-------------------|
| 공략 A/S | 위험 감수 여부 | 세컨샷 해저드(Q2) / 좁은 티샷(Q5) / 핀 공략(Q10) ✓ |
| 접근 F/T | 감으로 푸는가, 원인을 찾는가 | 미스샷 대응(Q3) / 레슨 수용 방식(Q7) / 거리 판단(Q11) ✓ |
| 목적 W/J | 결과 중심인가 경험 중심인가 | 내기 제안(Q4) / 라운드 후 기억(Q8) / 동반자와의 비교심리(Q12) ✓ |
| 멘탈 I/G | 실수·긴장 상황 회복력 | 첫 홀 OB(Q1) / 주시받는 티샷(Q6) / 퍼트 미스(Q9) ✓ |

### 4-2. 전부 A / 전부 B 선택 시

- 전부 A → **AFWI (전 축 67%)**, 전부 B → **STJG (전 축 67%)**
- 축당 1문항 매핑을 뒤집어 놓아 한쪽으로만 찍어도 극단값(100%)이 아닌 자연스러운 결과 ✓

### 4-3. 16유형 도달 가능성

- 4축이 문항 단위로 완전 독립(교차 채점 없음) → 2⁴ = 16유형 전부 도달 가능 ✓
- 단, "16개가 나온다"와 "16개가 다 다른 사람으로 느껴진다"는 별개 문제 → **2단계에서 1글자 차이 이웃 유형 간 차별성 검증** (stage2-content.md 참고)

### 4-4. 선택지 편향 점검

- 모든 문항 A/B 양쪽을 긍정적·유머로 서술, "정답처럼 보이는 쪽" 없음 ✓
- 유리멘탈·힐링 선택지는 자기비하 유머로 오히려 고르고 싶게 처리 ✓
- 스윙 이론 지식 없이 라운드 경험만으로 답 가능 ✓
