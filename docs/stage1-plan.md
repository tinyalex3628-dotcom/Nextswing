# 스윙 유형 테스트 — 1단계 기획 (축 설계 + 문항 + 채점 로직)

> 상태: **검수 대기** (사용자 확정 후 2단계 진행)

## 1. 축 4개

유형 코드 순서: **공략 → 접근 → 목적 → 멘탈** (예: `AFWI`)

| # | 축 이름 | 코드 | 설명 |
|---|---------|------|------|
| 1 | 코스 공략 | **A** 공격형 / **S** 안전형 | 해저드를 넘길 것인가, 끊어갈 것인가. 위험 감수 성향 |
| 2 | 스윙 접근 | **F** 감각형 / **T** 분석형 | 감으로 맞추는가, 원인을 파고드는가 |
| 3 | 라운드 목적 | **W** 승부형 / **J** 힐링형 | 스코어·내기에 진심인가, 분위기·그늘집이 본체인가 |
| 4 | 멘탈 | **I** 강철멘탈 / **G** 유리멘탈 | OB 한 방에 무너지는가, 바로 리셋되는가 |

설계 노트:
- 참고 예시의 "파워vs컨트롤"과 "공격vs안전"은 실제로 거의 같은 성향을 재므로 하나(코스 공략)로 합침.
- 대신 한국 아마추어 골프 문화에서 가장 공감대가 큰 **"승부 vs 힐링"** 축(내기, 그늘집, 단톡방 사진)을 추가.
- 멘탈 축은 자기비하 유머가 가장 잘 터지는 축이라 유지. "유리멘탈"은 공유 유발 포인트.
- 코드 8종(A/S/F/T/W/J/I/G) 모두 중복 없음.

## 3. 채점표

- 선택지 하나당 해당 극에 **+2점**. 축당 3문항 → 축 총점 6점.
- 축별 점수 조합은 6:0 / 4:2 / 2:4 / 0:6 만 가능 → **동점(3:3) 구조적으로 불가능**.
- 유형 코드 = 각 축에서 점수가 높은 극의 알파벳 4개 조합 (공략→접근→목적→멘탈 순).
- 결과 화면 퍼센트 = 축 점수 / 6 × 100 (표시값: 100% / 67% / 33% / 0%).

| 축 | 문항 | 극1 (+2) | 극2 (+2) |
|----|------|----------|----------|
| 공략 | Q2, Q5, Q10 | A(공격): Q2-A, Q5-A, Q10-B | S(안전): Q2-B, Q5-B, Q10-A |
| 접근 | Q3, Q7, Q11 | F(감각): Q3-A, Q7-B, Q11-A | T(분석): Q3-B, Q7-A, Q11-B |
| 목적 | Q4, Q8, Q12 | W(승부): Q4-B, Q8-A, Q12-A | J(힐링): Q4-A, Q8-B, Q12-B |
| 멘탈 | Q1, Q6, Q9 | I(강철): Q1-A, Q6-A, Q9-B | G(유리): Q1-B, Q6-B, Q9-A |

## 4. 자체 검증표

### 4-1. 축 내 일관성 (같은 축 3문항이 같은 성향을 재는가)

| 축 | 3문항이 재는 공통 성향 | 상황 다양성 |
|----|------------------------|-------------|
| 공략 A/S | 위험 감수 여부 (해저드 도전 / 좁은 홀 드라이버 / 핀 직접 공략) | 세컨샷·티샷·어프로치로 분산 ✓ |
| 접근 F/T | 문제 해결·준비를 감으로 하는가 이론으로 하는가 | 미스샷 대응·라운드 준비·클럽 선택 ✓ |
| 목적 W/J | 스코어 중심인가 경험 중심인가 | 내기·라운드 복기·대기 상황 ✓ |
| 멘탈 I/G | 실수·긴장 상황에서의 회복력 | OB·주시받는 티샷·퍼트 미스 ✓ |

### 4-2. 전부 A / 전부 B 선택 시

- 전부 A → 공격4:안전2, 감각4:분석2, 승부4:힐링2, 강철4:유리2 = **AFWI (전 축 67%)**
- 전부 B → **STJG (전 축 67%)**
- 축당 1문항 매핑을 뒤집어 놓았기 때문에 한쪽으로만 찍어도 극단값(100%)이 아닌 자연스러운 유형이 나옴. 결과 자체도 "감으로 지르는 승부사 / 신중한 분석형 힐링파"로 말이 됨 ✓

### 4-3. 16유형 도달 가능성

- 4축이 문항 단위로 완전히 독립(교차 채점 없음) → 각 축에서 양극 모두 도달 가능 → 2⁴ = 16유형 전부 도달 가능 ✓
- 예: `SFJG`가 나오려면 Q2-B·Q5-B·Q10-A / Q3-A·Q7-B·Q11-A / Q4-A·Q8-B·Q12-B / Q1-B·Q6-B·Q9-A — 실제 선택 가능한 조합 ✓

### 4-4. 선택지 편향 점검

- 모든 문항에서 A/B 둘 다 긍정적이거나 웃기게 서술 — "정답처럼 보이는 쪽" 없음 ✓
- 유리멘탈·힐링 계열 선택지는 자기비하 유머로 처리해 오히려 고르고 싶게 만듦 ✓
- 라운드 경험만 있으면 답할 수 있는 상황형 질문 (스윙 이론 지식 불필요) ✓
