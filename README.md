# NextSwing — 스코어 누수 분석기

> 오늘 몇 타 쳤는지 말고, **왜 그렇게 쳤는지.**

흔한 스코어 기록 앱이 아닙니다. 라운드에서 있었던 일(OB, 3퍼트, 무리한 공략…)을
30초만 입력하면, 스코어가 **어디서 새었는지** 캐디처럼 사람 말로 설명해 주는
웹앱입니다.

## 무엇을 해주나

- **누수 진단** — "오늘 95타의 가장 큰 원인은 퍼팅이 아닙니다. 티샷에서 +6타가 새었습니다."
- **카테고리별 누수 랭킹** — 티샷 / 세컨드 의사결정 / 100m 이내 / 그린 위, 🥇🥈🥉와 막대로 표시
- **사람 말 진단문** — "당신은 실력이 부족해서 95타를 친 게 아닙니다. 위험한 상황에서 보기를 더블보기로 키우고 있습니다."
- **단 하나의 처방** — "다음 라운드에서는 이것 하나만 바꾸세요."
- **SNS 공유 카드** — 결과를 1080×1350 이미지 카드로 만들어 저장·공유
- **라운드 히스토리** — 브라우저(localStorage)에만 저장, 지난 라운드 대비 누수 증감 표시

## 누수 계산 방식

입력한 사건 횟수에 카테고리별 가중치를 곱해 타수 손실로 환산합니다.

| 사건 | 카테고리 | 환산 |
|---|---|---|
| 티샷 OB·페널티 | 티샷 | 2.0타/회 |
| 티샷 트러블(탈출만 한 홀) | 티샷 | 1.0타/회 |
| 무리한 공략 실패(파5 투온 욕심 등) | 세컨드 의사결정 | 1.5타/회 |
| 100m 이내 그린 미스 | 100m 이내 | 0.8타/회 |
| 벙커 탈출 실패 | 100m 이내 | 1.0타/회 |
| 3퍼트 이상 홀 | 그린 위 | 1.0타/회 |
| 짧은 퍼트(1.5m) 미스 | 그린 위 | 1.0타/회 |

더블보기 이상 홀 수는 누수 계산이 아니라 패턴 진단(리스크 관리형 진단문)에 씁니다.

## 실행 / 배포

빌드 도구 없는 정적 단일 파일입니다.

- 로컬: `index.html`을 브라우저로 열면 끝
- 배포: GitHub Pages 활성화(Settings → Pages → Deploy from branch)만 하면 바로 서비스 가능

비상업 사이드 프로젝트이며, 입력한 기록은 서버로 전송되지 않고 브라우저에만 저장됩니다.
