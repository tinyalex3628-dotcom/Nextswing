# 골프 레슨 유튜브 촬영 대본집

카메라 3대 · 1인 촬영 기준으로 만든 골프 레슨 영상 대본 7편.
낭독 · 시선 연습용으로 글씨를 키운 **A4 세로 인쇄본**입니다.

## 바로 인쇄할 파일

`pdf/` 폴더에 있습니다. A4 세로로 그대로 인쇄하면 됩니다.

| 파일 | 내용 | 쪽수 |
|---|---|---|
| `골프레슨_대본_전체.pdf` | 표지 + 사용법 + 대본 7편 전체 | 68쪽 |
| `00_대본_사용법.pdf` | 기호 설명 · 카메라 세팅 · 말하기 연습법 | 4쪽 |
| `01_슬라이스_교정.pdf` | 슬라이스, 이제 진짜로 끝냅시다 | 10쪽 |
| `02_드라이버_비거리.pdf` | 드라이버 비거리, 힘 빼고 20m 늘립니다 | 9쪽 |
| `03_아이언_뒤땅_토핑.pdf` | 뒤땅과 토핑은 사실 같은 병입니다 | 9쪽 |
| `04_어드레스_그립_정렬.pdf` | 스윙의 8할은 치기 전에 결정됩니다 | 9쪽 |
| `05_백스윙_상하체분리.pdf` | 백스윙, 팔로 들지 말고 몸으로 감으세요 | 9쪽 |
| `06_어프로치_거리감.pdf` | 30m 어프로치, 거리감의 정체 | 9쪽 |
| `07_퍼팅_3퍼트탈출.pdf` | 3퍼트가 사라지는 퍼팅 루틴 | 9쪽 |

촬영할 편만 뽑아서 쓰려면 편별 PDF를, 한 번에 묶어두려면 전체 PDF를 인쇄하세요.

## 대본 한 편 구성

- 촬영 정보 박스 (촬영 시간 · 준비물 · 장소 · 핵심 메시지)
- 러닝타임 표 (타임코드별 구성과 분량)
- 장면 블록 — `카메라` 지시 / 대사 / `시연` 지시 / `자막` 메모
- 대사는 15pt, ● 표시 한 덩어리가 한 호흡

편당 대사 약 3,000자 → 낭독 9~10분, 시연·여백 포함 **편집본 12~14분**,
실제 촬영은 재촬영 포함 **20~30분** 기준입니다.

## 파일 수정하고 다시 만들기

대본 내용은 `src/*.html`에, 인쇄 스타일은 `assets/print.css`에 있습니다.
고친 뒤 아래 명령으로 HTML과 PDF를 다시 생성합니다.

```bash
python3 build.py
```

- `html/` — 브라우저에서 열어볼 수 있는 편별 HTML (브라우저 인쇄도 가능)
- `pdf/`  — 인쇄용 PDF

빌드에는 Chromium(헤드리스)과 한글 폰트 `Noto Sans CJK KR`이 필요합니다.

```bash
apt-get install -y fonts-noto-cjk
```

글씨 크기를 더 키우려면 `assets/print.css`의 `.say p { font-size: 15pt; }`
값을 조정하세요.
